# Additional Features

### 1. Page

- EduInk 앱에서는 기본적으로 사용자가 원하는 대로 페이지를 추가할 수 있고, 그 페이지는 현재 페이지 바로 밑에 생성된다.
- 페이지 분량, 페이지의 모양은 A4, A3 등등 종이 규격의 표준적 포맷을 따른다. 기본옵션은 가장 대중적인 A4 용지를 선택한다.
- 사용자가 현재 페이지를 터치하여 위로 밀어 올리면 아래에서 자동으로 현재 페이지와 동일한 규격, 동일한 스타일의 페이지가 생성된다.
- 사용자는 설정에서 페이지 분리형 문서 포맷 / 내용이 추가되는 대로 페이지가 분리되지 않고 계속 하나의 페이지에서 내용을 작성할 수 있는 포맷 을 언제든지 선택 가능하다.



### 2. Font

- 사용자는 폰트를 선택할 수 있다.
- 폰트를 추가할 수 있다. 폰트는 사용자의 로컬 디렉토리에서 ttf, otf 파일 등을 추가하면 노트 앱 내의 폰트 리스트에 추가 된다.
- 사용자가 최근에 선택한 폰트들은 맨 위에 따로 구분하여 표시 및 추천한다.
