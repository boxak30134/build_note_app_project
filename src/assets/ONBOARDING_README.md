# EduInk Studio 시작 가이드 (README)

**EduInk Studio**에 오신 것을 환영합니다!  
EduInk Studio는 **마크다운 노트·수식 편집**, **S-Pen 저지연 벡터 필기**, **말풍선 AI 튜터**, **`[[위키링크]]` 지식 연결**을 한 화면에서 함께 다루는 하이브리드 학습·연구 워크스페이스입니다.

---

## 1. 화면 구성 한눈에 보기

| 영역 | 주요 역할 |
| --- | --- |
| **상단 헤더** | 좌/우 사이드바 토글, 문서 제목 입력, `Ctrl+S` 저장, **`+ 첨부`**(PDF·이미지·카메라·표·말풍선) |
| **필기 툴바** | 텍스트 커서 / 펜슬 / 형광펜 / 지우개 / 올가미, 3색 슬롯(더블클릭으로 색상 변경), 굵기, 통합 Undo/Redo |
| **좌측 사이드바** | 폴더/노트 트리, 제목·본문 검색, 새 노트/폴더 생성, 휴지통, **로컬 파일·삼성 노트·PDF 가져오기** |
| **중앙 작업공간** | 멀티 탭 편집기(마크다운·$\text{KaTeX}$ 수식) + 투명 벡터 필기 캔버스 + 말풍선 주석(`💬`) |
| **우측 사이드바** | **AI 튜터**(무료 Gemini API 키 온보딩 및 현재 노트 전체 문맥 질의응답·요약) |

---

## 2. S-Pen 필기 및 터치 제스처

- **펜(스타일러스) 전용 필기**: S-Pen이나 스타일러스로 화면에 닿으면 즉시 필기(또는 지우개/올가미)만 동작하며, 화면이 끌리지 않도록 터치 패닝과 완전히 격리되어 있습니다.
- **배럴 버튼 지우개**: S-Pen 배럴 버튼을 누른 채 문지르면 도구를 전환하지 않아도 바로 지우개로 동작합니다.
- **손가락 터치 탐색**: 한 손가락 드래그로 스크롤/이동하고, 두 손가락 핀치로 확대·축소할 수 있습니다. (펜 사용 직후 450ms 동안 손바닥 터치는 자동 무시됩니다.)
- **마우스 필기**: 상단 툴바의 마우스 필기 토글을 켜면 태블릿 펜이 없는 PC 환경에서도 마우스로 필기할 수 있습니다.

## 3. 문서 작성 · 삽입(`+`) · 지식 연결

1. **마크다운 & 수식**: `#` 제목, `-` 목록, ` ``` ` 코드 블록과 함께 `$E = mc^2$` 같은 인라인/블록 $\LaTeX$ 수식을 바로 입력할 수 있습니다.
2. **`+ 첨부` 메뉴 활용**:
   - **PDF**: PDF를 불러와 페이지 위에 직접 S-Pen으로 필기할 수 있습니다.
   - **이미지 / 카메라 / 표**: 사진 첨부, 카메라 촬영, $3 \times 3$ 표 삽입을 지원합니다.
   - **말풍선 (`💬`)**: 텍스트를 선택하거나 `+ 첨부`에서 말풍선을 추가해 핀 형태로 접어두고 AI에게 부분 질문을 할 수 있습니다.
3. **위키링크 & 문서 연결**: 본문에서 `[[`를 입력하면 다른 노트를 즉시 검색해 연결할 수 있으며, 텍스트를 드래그한 뒤 **`🔗 문서 연결`**을 누르면 연관 노트를 추천해 줍니다.
4. **즉석 번역**: 텍스트를 드래그하고 **`[번역]`**을 누르면 API 키가 없어도 바로 단어/문장 인라인 번역(`<ruby>`)을 확인할 수 있습니다.

---

## 4. AI 튜터 & 저장 · 백업 안내

- **AI 튜터 시작하기**: 우측 AI 사이드바에서 Google AI Studio(`aistudio.google.com`) 무료 Gemini API 키를 입력하면 현재 노트를 바탕으로 요약, 개념 설명, 질문 응답을 받을 수 있습니다.
- **자동 저장 및 백업**: 작성한 노트와 필기는 브라우저 로컬 저장소(IndexedDB/OPFS)에 자동 저장됩니다. 상단 또는 사이드바에서 **Markdown / PDF 내보내기**와 **Google Drive 동기화**로 안전하게 백업할 수 있습니다.

> 💡 **팁**: 왼쪽 **`수업 자료`** 폴더에 있는 **`인지부하 이론`**, **`멀티미디어 학습 원리`** 샘플 노트를 열어 `[[` 위키링크와 필기 기능을 바로 체험해 보세요!
